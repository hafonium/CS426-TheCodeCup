# ☕ The Code Cup
- A modern Android application built for a fictional coffee shop, powered by Clean Architecture and a robust Python FastAPI backend.

- The Code Cup allows users to seamlessly browse menus, place orders, earn reward points, and manage their profiles with a secure, server-authoritative backend.

## 🚀 Key Features
- **Client-Server Architecture:** Robust RESTful API design ensuring smooth separation of concerns.

- **Security & Authentication:** Modern authentication pipeline using JWT access tokens and Custom OTP verification.

- **Server-Authoritative Logic:** Game logic and reward mechanics (e.g., Gacha System) executed safely on the backend to prevent client-side tampering.

- **UI State Management & Integrations:** Reactive Jetpack Compose UI backed by external API integrations.

## 🛠 Tech Stack
### Frontend (Android)
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose

## Backend
- **Framework:** FastAPI (Python)
- **ORM:** SQLAlchemy 2.0
- **Database:** Serverless Postgres via Neon Cloud
